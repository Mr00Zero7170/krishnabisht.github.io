# Krishna Bisht — Portfolio

Personal portfolio: [krishnabisht.me](https://krishnabisht.me)

A small, responsive site to introduce me, share the machine learning projects I’m building, and make it easy to get in touch.

## Why I built it

I wanted one clear place to show what I’m learning in computer science and AI/ML, explain the ideas behind my projects, and connect with people working on practical machine learning. I also wanted the site itself to feel like me: focused, curious, and a little atmospheric without getting in the way of the work.

## What I learned

- Structuring a portfolio with semantic HTML and accessible navigation.
- Building a responsive layout and a consistent visual system with CSS.
- Adding subtle animation while respecting reduced-motion preferences.
- Writing project summaries that explain both the idea and the technical approach.
- Publishing a static site with GitHub Pages and connecting a custom domain.

## Built with

HTML, CSS, and a little JavaScript. No framework or build step.
